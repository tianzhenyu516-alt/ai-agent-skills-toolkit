# ai-skill-code-review

AI skill for evidence-based code review and security-aware change analysis.

## What it does

Review a code change for concrete correctness, security, and regression issues, with file-level evidence and prioritized findings.

## Install

Copy the `code-review` folder into your AI assistant's skills directory, then invoke the `code-review` skill for a matching task. The skill consists of a single self-contained [`SKILL.md`](SKILL.md). No API key or bundled scripts are required.

## Example request

> Use the `code-review` skill to work on my project, and report what you changed and verified.
