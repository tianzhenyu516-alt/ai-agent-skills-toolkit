# ai-skill-review-feedback

AI skill for handling code review feedback with verification and clear responses.

## What it does

Evaluate code review feedback against the implementation, make justified changes, and verify each fix.

## Install

Copy the `review-feedback` folder into your AI assistant's skills directory, then invoke the `review-feedback` skill for a matching task. The skill consists of a single self-contained [`SKILL.md`](SKILL.md). No API key or bundled scripts are required.

## Example request

> Use the `review-feedback` skill to work on my project, and report what you changed and verified.
