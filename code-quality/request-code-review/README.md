# ai-skill-request-code-review

AI skill for preparing effective code review requests and PR review briefs.

## What it does

Prepare a focused review request with a precise diff, requirements, risk areas, and verification evidence.

## Install

Copy the `request-code-review` folder into your AI assistant's skills directory, then invoke the `request-code-review` skill for a matching task. The skill consists of a single self-contained [`SKILL.md`](SKILL.md). No API key or bundled scripts are required.

## Example request

> Use the `request-code-review` skill to work on my project, and report what you changed and verified.
