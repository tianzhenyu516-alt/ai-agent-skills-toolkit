# ai-skill-openmv-vision

OpenMV machine vision development skill.

## Purpose

Build OpenMV camera scripts with explicit sensor setup, image processing assumptions, bounded outputs, and board tests.

## Install

Copy the `openmv-vision` folder into your AI assistant's skills directory. Then ask the assistant to use the `openmv-vision` skill for a matching project. Start with [`openmv-vision/SKILL.md`](SKILL.md) and keep any referenced board notes with it. No API key, bundled script, or particular plugin is required.

## What to provide

Give the assistant your **exact chip model, development board/module and hardware revision**, plus a **datasheet, board schematic, or pinout document** as a link or local path. Also provide your repository location, goal, and available build or hardware tools. The skill instructs the assistant to ask for these details before suggesting pin assignments.
