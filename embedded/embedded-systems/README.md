# ai-skill-embedded-systems

AI skill for STM32, ESP32 and RTOS firmware development and review.

## What it does

Develop and review microcontroller firmware with attention to hardware limits, interrupts, timing, and validation on the target board.

## Install

Copy the `embedded-systems` folder into your AI assistant's skills directory, then invoke the `embedded-systems` skill for a matching task. The skill consists of a single self-contained [`SKILL.md`](SKILL.md). No API key or bundled scripts are required.

## Example request

> Use the `embedded-systems` skill to work on my project, and report what you changed and verified.

For pin assignments, provide the exact chip, board or module revision, and its datasheet, schematic, or pinout document. The skill asks for these before proposing board-specific wiring.
