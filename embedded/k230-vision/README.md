# ai-skill-k230-vision

K230 embedded vision and edge AI development skill.

## Purpose

Develop K230 camera and vision applications with validated image pipeline, model conversion, deployment, and device evidence.

## Install

Copy the `k230-vision` folder into your AI assistant's skills directory. Then ask the assistant to use the `k230-vision` skill for a matching project. Start with [`k230-vision/SKILL.md`](SKILL.md) and keep any referenced board notes with it. No API key, bundled script, or particular plugin is required.

## What to provide

Give the assistant your **exact chip model, development board/module and hardware revision**, plus a **datasheet, board schematic, or pinout document** as a link or local path. Also provide your repository location, goal, and available build or hardware tools. The skill instructs the assistant to ask for these details before suggesting pin assignments.
