# ai-skill-autopilot-workflow

Standalone AI skill for end-to-end software task execution.

## What it does

Carry a scoped software task from requirements through implementation and validation with explicit checkpoints and honest status reporting.

## Install

Copy the `autopilot-workflow` folder into your AI assistant's skills directory, then invoke the `autopilot-workflow` skill for a matching task. The skill consists of a single self-contained [`SKILL.md`](SKILL.md). No API key or bundled scripts are required.

## Example request

> Use the `autopilot-workflow` skill to work on my project, and report what you changed and verified.
