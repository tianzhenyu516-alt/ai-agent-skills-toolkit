# ai-skill-jupyter-notebook

Self-contained AI skill for reproducible Jupyter notebooks.

## What it does

Create, edit, and validate self-contained Jupyter notebooks for experiments or tutorials without external templates.

## Install

Copy the `jupyter-notebook` folder into your AI assistant's skills directory, then invoke the `jupyter-notebook` skill for a matching task. The skill consists of a single self-contained [`SKILL.md`](SKILL.md). No API key or bundled scripts are required.

## Example request

> Use the `jupyter-notebook` skill to work on my project, and report what you changed and verified.
