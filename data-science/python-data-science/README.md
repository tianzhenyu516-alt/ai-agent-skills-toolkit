# ai-skill-python-data-science

Python data science and reproducible analysis skill.

## Purpose

Create reproducible Python data analysis with explicit inputs, validation, leakage checks, and honest results.

## Install

Copy the `python-data-science` folder into your AI assistant's skills directory. Then ask the assistant to use the `python-data-science` skill for a matching project. Start with [`SKILL.md`](SKILL.md). No API key, bundled script, or particular plugin is required.

## What to provide

Provide the dataset location and format, the question to answer, variable definitions if available, and any limits on sharing the data. Say which Python environment and packages are available. The skill asks the assistant to validate inputs and distinguish measured results from assumptions.
